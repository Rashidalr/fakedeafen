# fakedeafen
fakedeafen on discord without Vencord

# The way
1 - git clone https://github.com/Vendicated/Vencord
2 - cd Vencord
3 - npm i -g pnpm
4 - pnpm install
5 - [ # Create New folder ( userplugins ) ]
5 - cd src/userplugins
6 - [ # install your plugin here ]
7 - pnpm build
8 - pnpm inject
9 - Run Discord 
10 - Go to Settings
11 - Go to plugins [Vencord]
12 - Search FakeDeafen
13 - Keep run .
